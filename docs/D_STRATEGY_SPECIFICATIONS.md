# Course hypothesis reconstruction specifications

Status: implemented research rules; default disabled; no financial promotion. This document specifies nine source-derived concepts. Grid and triangular arbitrage have separate stateful specifications. Source cell indices are zero-based. Original notebooks were statically read, never executed.

## Shared mathematical and engineering contract

Input is an immutable observed prefix of valid positive-price OHLCV rows. Each row has timezone-aware `close_time` and `available_at`, with `close_time <= available_at <= decision_time`. Timestamps must be strictly increasing and unique. The input is rejected wholesale if any row is future/unavailable, revised, open, nonfinite, negative-volume or has invalid OHLC geometry. Candle close timestamps establish closure; optional `is_closed`, `revision`, `quality_status`, `open_time` add checks. Current staleness reference is 4h, explicitly an unverified engineering parameter; it does not grant acceptance for intrabar execution or create market-depth history. Real venues/dataset eligibility remain the existing orchestration/governance responsibility.

Definitions: `C_t` close; `H_t`, `L_t` high/low. `SMA_n(t) = sum(C[t-n+1:t])/n`; EMA adjusted and recursive forms are distinguished below. Signals become known only after the final input's availability. Every candidate retains the actual latest observation time and maximum availability time. `earliest_execution_time > decision_time` is a strict lower bound only; the first future executable quote and simulator determine execution and fill price. It is never a same-close fill assumption.

Every enabled strategy with sufficient warm-up emits one immutable `HypothesisCandidate`, including direction zero when conditions fail. Disabled/insufficient-warm-up strategies emit an empty list. No edge or confidence has been empirically established: both remain `None`, uncertainty penalty is a conservative reference of 1, and mapping to existing `SignalEvidence` remains `NO_TRADE` with `UNESTIMATED_EDGE_OR_CONFIDENCE`. Snapshot, configuration and implementation hashes bind deterministic identities. Mutation of returned parameter copies does not change strategy configuration. These are entry hypotheses, not standalone position managers.

The versioned JSON gives each parameter type, unit, range, reference, source cell, method, version and `UNVERIFIED` scientific status. Enabling a research adapter changes its configuration hash and does not authorize paper/live orders. Existing risk limits are untouched. Costs are round-trip return fractions, reference 24bps, not estimated actual execution costs. Exit metadata are research price-fraction references rather than modifications of the canonical Risk Engine. Timeout 30 observed bars and any missing stop reference are `ENGINEERING_EXTENSION`. These references require a separately registered experiment before economic inference.

## RSI and EMA conventions

Notebook 5 computes delta, positive gains and absolute losses; the first difference is converted to zero by `where`. Smoothed averages use pandas adjusted EWM with alpha=1/14: weighted finite-prefix sums normalized by weight sum. This is **not** Wilder RSI initialized by a 14-observation SMA and then recursively updated. Standalone MACD uses `ewm(span=...).mean()` default `adjust=True`. Confluence deliberately uses recursive price EMAs but adjusted signal EMA. Retaining these differences makes reconstruction auditable rather than silently standardizing course examples.

Notebook 6 RSI uses sums of positive/negative changes across the final 14 differences divided by14. This implementation preserves that simple-window definition. An all-flat window has undefined ratio and yields a standaside rather than silently assigning a neutral50 or buying with fabricated probability. Monotonically rising windows produce100, falling windows0. Both calculations are causal and require no learned scaler or fitted preprocessing.

## Failure conditions and limits

No claim is made that these parameters are optimal or that any rule is profitable. Technical short hypotheses do not confer spot short-selling capability. The scalper's absolute5000 threshold is an educational arithmetic condition; a 4h close proxy cannot validate genuine short-horizon scalping. Order-book imbalance has no valid historical backtest without first-seen timestamped depth snapshots. Snapshot sequence absence, staleness, crossed/unsorted levels, market mismatch or insufficient depth are errors, not neutral substitutes for valid data.

Source notebook examples directly submit orders, sometimes submit a take-profit sell before confirming a buy fill, repeatedly poll/train without durable provenance and assume historical close execution. Those side effects and account arithmetic are not migrated. Hypothesis generators have no credential, transport, HTTP or order methods; existing deterministic risk and research-only execution authorization retain control.

Exit references are emitted as invalidation metadata. Position lifecycle, gap handling, within-bar TP/SL ambiguity, fees, timeout settlement and latency must be resolved by the experiment's existing execution simulator or explicit evaluation model; they are not claimed as implemented broker execution by this rule adapter. Shared event simulator integration must not fill limit orders solely from an OHLC touch.

## Acceptance and rollback

Acceptance requires positive and standaside fixtures, independent RSI finite-weight calculation, explicit EMA difference, prefix invariance, malformed/future input rejection, real availability propagation, deterministic identities, mutation isolation and all nine defaults disabled. Recorded pytest output is engineering evidence only. Rollback disables/removes the course adapter registration and restores the configuration; historical evidence artifacts and scientific versions remain immutable.

## Executable six-baseline event and label reconstruction

`research_bot/course/labels.py::replay_course_events` now implements completed offline events for the six candle-based course strategies. Its input additionally requires aware `open_time`; candle intervals must be non-overlapping. A strategy signal from prefix ending at bar t may enter at bar t+1's actual open only if every prefix row was available strictly before that open. Delayed data cannot receive a retrospective next-open fill. Equal availability/open timestamps do not establish processing or transmission latency and receive no such fill under this conservative reference model.

The replay permits one hypothetical position per strategy and symbol. It preserves the source TP/SL fractions and source indicator exits listed above, including the opposing MACD cross in notebook5 cell16 confluence. Stops/targets apply to the actual next-open entry price. If the opening price gaps beyond a stop, the exit price is that adverse open; favorable target gaps are capped at the target. Both TP and SL touched inside one bar are resolved SL first. An exact intrabar fill timestamp is not known from OHLCV; its recorded close-time bound and `exit_timestamp_resolution` explicitly represent that limitation. An indicator exit or observed-bar timeout is known only from an available closed bar and executes at a subsequent eligible open. Pending indicator exits never override an adverse gap-stop classification. No same-open reentry is modeled. These fill, single-position and reentry conventions are `ENGINEERING_EXTENSION` rather than source evidence of realizable execution.

Timeout30 bars is a preregistration reference added by engineering: after30 observed held bars, close is requested for a later open. Consequently measured holding bars can exceed30 by the next-open settlement bar or data delay. This is not an autonomous order retry or an alteration of existing risk limits. Unclosed terminal positions are omitted from completed-event labels and are not force-closed by the dataset boundary. Evaluation must disclose this right-censoring and include unresolved positions/exposure when drawing economic conclusions.

A frozen `CourseBaselineEvent` records candidate and event identities; strategy/config hashes; the SHA of only the consumed input prefix; actual decision/evidence availability, entry/exit and label availability; direction; modeled prices; TP/SL/TIMEOUT/INDICATOR_EXIT outcome; bars held; and dimensionless directional returns. `gross_return = direction*(exit_price/entry_price−1)`. Short returns are hypothetical return arithmetic: funding, borrowing, margin, liquidation and short market capability remain unvalidated. They do not establish spot short executability or a broker-wealth accounting model.

Cost is one registered round-trip return fraction: `net_return = gross_return − cost_bps/10000`. The default replay cost is zero so an existing scientific evaluator may apply its registered scenario exactly once to gross events. If replay cost is explicitly supplied, downstream evaluators must consume net returns without charging it a second time. Original course fee/portfolio arithmetic is not imported as an economic result. The returned completed events are suitable for the existing evaluator and evidence ledger; they have no order transport or risk authorization path.

Ticker-poll scalper, ticker RSI+MA and book-imbalance lifecycle labeling is explicitly `UnsupportedCapability` in this candle replay. Their ticker clocks, actual fill-dependent take-profit sells, stop monitoring and recorded depth are not available from candle substitution. That limitation remains an integration/evidence gate rather than a fabricated claim of full course-bot execution.
